    2. BFS has more node expansions than DFS, meaning it is less efficient. 
    BFS guarantees an optimal solution because of how it expands the nodes. DFS just picks a path and expands it all the way down. So while it does find a path, that doesn't mean it's optimal, it was just the first successful path the algorithm found. BFS succeeds because it expands every node on the same level first before moving on, meaning that the first successful node it finds is the shallowest leaf node. In other words, the optimal solution
    While BFS may get you the optimal solution, it is not as efficient. If all the possible solution nodes are deep paths, it will take a while to reach the first solution node. Whereas DFS doesn't expand much, so it's very efficient at finding a solution (not neccessarily the optimal though)
